# Django Todos App

A simple Todo web application built with Django that allows users to manage daily tasks using full CRUD operations.

## Features

- Add new tasks
- View all tasks
- Update existing tasks
- Delete tasks
- Clean and simple interface

## Tech Stack

- Python
- Django
- HTML
- CSS
- Bootstrap
- SQLite

## Installation

1. Clone the repository

```bash

git clone https://github.com/Irfa-Imran/Todos-App-using-Django.git

cd Todos-App-using-Django

2. Create a virtual environment

python -m venv venv

3. Activate the virtual environment

```for Windows:
venv\Scripts\activate

```for Mac:
source venv/bin/activate

4. Install dependencies

pip install -r requirements.txt

5. Run migrations

python manage.py migrate

6. Start server

python manage.py runserver

7. Open in browser

http://127.0.0.1:8000/
